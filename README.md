⚙️ Instalación y Uso
Clonar el repositorio:

Bash
git clone [https://github.com/mmarceee/eCommerceJAP.git](https://github.com/mmarceee/eCommerceJAP.git)
Abrir el proyecto:
Al ser un proyecto front-end estático, simplemente abre el archivo index.html en tu navegador preferido o utiliza una extensión como Live Server en VS Code.

📝 Notas de Desarrollo
El proyecto consume la API proporcionada por el curso para simular un entorno real de servidor. Los datos del usuario y el estado de la sesión se mantienen utilizando el almacenamiento local del navegador (localStorage).
